# About
This app lets you view the wireless devices in addition to other wireless battery that do not use Bluetooth natively:
<img width="407" height="237" alt="image" src="https://github.com/user-attachments/assets/52b09c36-e530-496f-bfd8-fe9132a09866" />

The idea came from my Razer mouse running out of battery, and I had to install Razer Synapse to see the battery status. Windows already shows the battery status for Bluetooth devices but my Razer devices and Audeze Maxwell headset require third party software just to view the battery status. Since it is too much to expect from Windows to give a notification when some of these devices have low battery I decided to throw Claude at the task. 

The app is implemented in .NET 10 and uses WinUI 3.
